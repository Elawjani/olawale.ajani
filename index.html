Service Design User Journey Public Sector Stakeholder Coordination Product Judgment How I Evaluate Product Quality For product design and AI evaluation tasks, I use structured judgment: identify the user goal, compare options, assess friction, and recommend the experience that best supports the user. Example: Onboarding Flow Question: Which onboarding flow creates less friction? Option A requires many fields before the user sees value. Option B asks only for essential information first. Recommendation: Option B, because it reduces cognitive load and helps users reach the core experience faster. Example: AI Response Quality Question: Which response better serves the user? Response A is technically correct but vague. Response B is accurate, structured, and actionable. Recommendation: Response B, because it better matches user intent and reduces the need for follow-up clarification.
